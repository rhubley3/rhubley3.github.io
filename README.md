# Portfolio template

A one-file portfolio site. Everything lives in `index.html`.

## Put it online for free with GitHub Pages

1. Sign in to github.com (a free account is enough).
2. Create a new public repository named `<your-username>.github.io`.
3. Upload `index.html` to it (Add file > Upload files > Commit).
4. Open Settings > Pages and make sure the source is the `main` branch.
5. After a minute or two the site is live at `https://<your-username>.github.io`.

## Editing

- Replace "Your Name" and the placeholder text.
- To use a photo on a card, replace `<div class="thumb t1"></div>` with
  `<img class="thumb" src="images/project1.jpg" alt="" style="width:100%;object-fit:cover">`
  and upload the image into an `images` folder.
- Copy a whole `<a class="card">...</a>` block to add a project.
